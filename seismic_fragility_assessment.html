Workflow

Five-step screening protocol

From design drawings to risk decision — without any nonlinear modelling. Fully compatible with prescriptive code compliance under BCP-2021 and MS EN 1998.

01
Extract Parameters
N (storeys), H (m), plan width/span, member sizes, roof/elevation regularity
02
Compute T̄, SR, λeff
Three dimensionless macro-parameters encoding period, stiffness regime, and slenderness
03
Evaluate Equations
Closed-form sparse regression equations yield μ̂ (median PGA capacity) for DS1–DS5

Map the frame against national hazard; classify Low / Moderate / High risk

Decision

Interactive Calculator

Enter your frame parameters

Use Enter from drawings for practitioner-style inputs such as storeys, height, span, and member sizes, or switch to Macro-Parameters to enter T̄, SR, and λeff directly. Editable fields intentionally allow out-of-domain values, but the calculator flags them before interpreting the result.

Input Mode
Structural inputs are converted internally using the PDF workflow equations: T = 0.075H^0.75, T̄ = T√(g/H), B = min(Wplan, Splan), SR = (bc·hc³ / bb·hb³)(B/H)³, Iv = 0 for a regular roof or Iv = ρtop/(N+ρtop) for an irregular roof, and λeff = (H/B)(1−Iv). Use consistent metre units for all dimensions. Foundation idealisation is not selected separately here because the equations operate on the final macro-parameters; if SSI-modified values are available, enter them directly in Macro-Parameters mode.

Effective vertical irregularity from top-floor coverage
What Iv means: Iv is the vertical irregularity modifier used in the PDF workflow. The top-floor bay coverage ratio is ρtop = occupied top bays / full lower-storey bays. For a regular full-height frame, Iv = 0. For an irregular roof/top floor, the tool applies Iv = ρtop/(N+ρtop), then computes λeff = (H/B)(1−Iv). For example, if the lower storeys have 3×3 = 9 bays but the top storey has 2×3 = 6 bays, then ρtop = 6/9 = 0.667 and Iv = 0.667/(N+0.667).

Fragility Curves

P(DS ≥ ds | PGA) — screening view

Lognormal fragility curves using P(DS≥ds|PGA) = Φ[ln(PGA/μ̂)/β]. By default, the graph shows the recommended screening view (DS1–DS3 only). Use the toggle below if you want to overlay DS4 and DS5 as dashed guide curves for research-style interpretation. The vertical dashed line marks your site PGA.

Default plot: DS1–DS3 screening curves only. When enabled, DS4/DS5 are shown as guide curves and the PGA axis expands if needed.

Damage-State Guide

How to interpret the damage states

The in-graph legend is intentionally compact. Use the guide below for the practical meaning and recommended interpretation of each damage-state equation. DS4 and DS5 are optional guide curves only and are hidden by default in the screening plot.

DS1 · Slight damage

Initial cracking or minor yielding. This is the main early-warning threshold and the preferred standalone screening result.

DS2 · Moderate damage

Repairable structural damage. Use as a secondary indicator for detailing review and engineering judgement.

DS3 · Extensive damage

Major nonlinear response and substantial repair demand. Treat as a damage-progression trend, not a direct design approval threshold.

DS4 · Complete damage

Near-collapse or complete damage state. Hidden by default and available only as an optional dashed guide curve because its low validation strength makes it unsuitable for standalone screening decisions.

DS5 · Collapse

Retained in the equation table for research transparency only. Hidden by default and available only as an optional dashed guide curve because only internal validation is currently available and collapse-state error is comparatively high.

About This Research

EIDA Framework — Extended IDA + ML

Prescriptive code compliance does not quantify the probability that a structure will exceed specific damage states under realistic seismic demand. This framework addresses that gap for low-to-mid-rise RC grid-like bare frames common in Pakistan and Malaysia — a class poorly represented in existing fragility databases.

Methodology Pipeline
  • → ETABS COM API: automated archetype parametrisation
  • → C# IDA automation: 180 archetypes × 9 GMs × incremental steps
  • → MATLAB post-processing: IDA curve extraction, DS thresholds
  • → GLME meta-regression: pooled fragility parameter estimation with SSI
  • → ML closed-form equations: LASSO, Elastic Net, OMP, Stepwise BIC
  • → External validation: FEMA 356, ASCE 41, PEER NGA-West2, independent studies
