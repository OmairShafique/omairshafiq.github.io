EIDA Framework — Automated Extended IDA Pipeline
Core PhD output · Under review in MethodsX (Q1)

Designed and deployed an end-to-end high-throughput automation pipeline that runs parametric nonlinear time-history analyses across thousands of RC frame configurations without manual intervention. The system handles automated topology extraction, stochastic material assignment, Hunt-and-Fill ground motion scaling to global collapse (DS1–DS5), Soil–Structure Interaction via Gazetas spring formulations, and real-time fragility curve generation.

A Direct Text Injection Protocol modifies nonlinear hinge properties and boundary conditions in real time via COM marshalling — enabling bulk parameter sweeps that would otherwise require weeks of manual ETABS setup.

ETABS 3D FE Model → C# API Controller → Hunt-and-Fill IDA → MATLAB Post-processing → GLME Meta-Regression → ML Closed-Form Equations
